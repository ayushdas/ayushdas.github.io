# ayushdas.github.io

Personal site of **Ayush Das**, Senior Data Scientist (AVP) at NatWest Group.

A single static page (`index.html`): no build step, no dependencies. It is hosted free on GitHub Pages.

- To change the photo, replace `photo.jpg` (square, at least 600×600). If it is missing, the page shows the initials.
- To edit content, change the text in `index.html` and push. The site updates within a minute.
